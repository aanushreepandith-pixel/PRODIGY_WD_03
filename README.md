# **PRODIGY_WD_03**

## **Tic-Tac-Toe Web Application - Interactive game with AI opponent**

## 📖 **Description**
A fun and interactive Tic-Tac-Toe web application built using HTML, CSS, 
and JavaScript. Players can compete against each other or challenge an 
AI opponent. The goal is to place three markers in a row — horizontally, 
vertically, or diagonally — to win the game.

## 🛠️ **Technologies Used**
- **HTML** – Game structure and layout
- **CSS** – Styling and visual design
- **JavaScript** – Game logic, AI opponent, and interactivity

## ✨ **Features**
- 🎮 Two-player mode (Player vs Player)
- 🤖 AI opponent mode (Player vs Computer)
- ✅ Win detection for rows, columns, and diagonals
- 🔄 Restart/Reset game functionality
- 📱 Responsive design for all screen sizes
- 🎯 Tracks current player's turn
- 🏆 Displays winner or draw result

## 🚀 **How to Play**
1. Open `index.html` in your browser
2. Choose to play against a friend or the AI
3. Players take turns clicking on the grid
4. First to get 3 in a row wins!
5. Click Restart to play again
